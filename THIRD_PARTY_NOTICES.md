## 运行时依赖 / Runtime dependencies

Rust 静态二进制与前端运行时依赖的完整第三方许可文本在镜像构建时从锁定依赖生成，随镜像分发于 `/usr/local/share/truenas-nvidia-driver-manager/THIRD_PARTY_LICENSES.txt`。本地可先运行 `cargo fetch --locked` 缓存 Rust 源码，再运行 `python3 tools/third-party-licenses.py` 得到同样内容；如存在 npm 运行时依赖，还需先运行 `npm --prefix web ci` 准备其源码。生成器本身不会下载依赖，缺少源码或许可文件时会失败。构建工具和仅用于开发的依赖不随运行时分发。

Full license texts for the Rust static binary's dependencies and frontend runtime dependencies are generated from locked dependencies during the image build and distributed at `/usr/local/share/truenas-nvidia-driver-manager/THIRD_PARTY_LICENSES.txt` in the image. To reproduce the same content locally, run `cargo fetch --locked` to cache Rust sources, then `python3 tools/third-party-licenses.py`; when npm runtime dependencies exist, first run `npm --prefix web ci` to prepare their sources as well. The generator never downloads dependencies and fails if sources or license files are missing. Build tools and development-only dependencies are not distributed in the runtime.
